# Portfolio 05 (`portfolio-05-kronen`)

AI Studio / Next.js 15 portfolio app powered by React 19, Tailwind CSS v4, and Motion.

## Features
- Next.js App Router
- Motion animations & Tailwind CSS v4
- Google GenAI integration support

## Development

Run locally from repository root:
```bash
pnpm dev:05
```

Or from `apps/portfolio-05-kronen`:
```bash
pnpm dev
```

## Build & Preview

```bash
pnpm build
pnpm start
```
