# Portfolio 004 (`portfolio-004`)

Vite + React 19 portfolio website with Express backend and Motion animations.

## Features
- Vite + React 19 (no Next.js — SPA)
- Express.js backend server
- Motion animations & Tailwind CSS v4
- Google GenAI integration support

## Development

Run locally from repository root:
```bash
pnpm dev:portfolio-004
```

Or from `apps/portfolio-004`:
```bash
pnpm dev
```

## Build & Preview

```bash
pnpm build
pnpm preview
```
